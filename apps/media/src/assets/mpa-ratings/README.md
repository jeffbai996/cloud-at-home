# MPA rating artwork

The G, PG, PG-13, R, and NC-17 block SVGs are the Motion Picture
Association's rating artwork, sourced from the corresponding
`MPA_<RATING>_RATING_(block).svg` files on Wikimedia Commons and optimized
with SVGO without changing their geometry.

Commons identifies each file as a public-domain text logo and notes that the
marks may still be protected as trademarks.
